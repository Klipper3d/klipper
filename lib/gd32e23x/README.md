# GD32E23x device headers

`include/` contains the vendor/CMSIS-compatible GD32E23x device headers used by
the Klipper platform code.  Runtime specializations belong in `src/stm32`.

The headers originate from GigaDevice's published GD32E23x firmware library.
They identify themselves as the GigaDevice GD32E23x 2020-12-12 V1.1.0 header
revision and retain GigaDevice's BSD-3-Clause notice.
