# v1.0.0 — Ender 3 V3 SE, stock display and BMCU

This release brings together the stock-display port and the switch-based BMCU
integration for the verified GD32F303RET6 Ender 3 V3 SE target.

## Changes

- Merge upstream Klipper through `0cee841e31d701595b3e509a0b502f6e320f52a8`,
  preserving this fork's board configuration and display bridge.
- Handle OrcaSlicer 2.4.2's automatic `T0` through a committed BMCU print map.
  Logical tools remain resolved by BMCU; existing explicit `B` commands work.
- Preserve native manual tool selection outside an active print map.
- Keep switch-based arrival, extruder-first capture, encoder-verified parking,
  purge/wipe and assisted unload sequences.
- Standardize maintained source and documentation in English, with English and
  Brazilian Portuguese README files and display localization.
- Remove personal machine snapshots, device UID bindings and personal slicer
  exports from the current source tree. Restore tests now use synthetic data.
- Keep private backup tools and compatibility with existing command names,
  configuration keys and backup formats.

## Dependencies and target

- Mainboard: verified CR4NS200320C14 with GD32F303RET6.
- Build: STM32F103-compatible target, 28 KiB bootloader, USART1.
- Optional BMCU: BMCU-Klipper 1.0.6 and BMCU firmware 1.0.1.
- Slicer integration: OrcaSlicer 2.4.2; one extruder with four filament slots.

## Upgrade

Back up your configuration before upgrading. Use the host source and MCU
firmware from this tag. Preserve PID, probe Z offset, bed mesh and extrusion
calibration; do not copy a new-printer template over a calibrated configuration.
Run `scripts/ender3-v3-se/install_multicolor.py` to update optional integration
modules on an already configured printer. The printer must be idle, channels
parked and entry sensor clear. Remove the former computer-side post-processing
script if it was configured in Orca. Replace `YOUR_BMCU_UID` in the public slicer
example with your own device UID.

## Validation and limitations

Release publication requires the Ender display/integration regression tests,
target firmware compilation, Klippy configuration validation and the general
Klipper build/test workflow to succeed for the release commit. Downloadable
firmware includes its source commit, target metadata and SHA256 checksums.

Physical validation covers one assembly, including capture, switch-controlled
unloading, purge/wipe and a two-color PETG print. It does not establish universal
support for every display/board revision, purge mechanism, material or four-color
print. Calibrate and commission the actual machine before printing.
This release does not include proprietary display firmware or automatic
PRTouch/HX711 Z-offset firmware.
